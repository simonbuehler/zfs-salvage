How the copy works

Every file is read block by block from the old disks and each block is verified by its ZFS checksum (falling back to the second copy). Files keep their original timestamps. A manifest records every file with its result and SHA-256 – download it from the list below. Files whose blocks cannot be verified are written as far as possible and marked “partial”. When a copy is complete, every file is hashed again on the target and compared with the SHA-256 from the source; only then is it called verified. An interrupted run is never trusted blindly: its last files are copied again on resume.
